## Final Posture

Public facades expose status and proof posture through
ordinary public proof surfaces in each owner crate. The closeout matrix records
the specific public API, posture accessor, and contract-test file for the topo
operator Query surface, spatial evidence-ledger surface, kernel closeout report
surface, and Forge Query Consumer Kit surface. The report is read-only to
ordinary consumers: matrix rows, dispositions, residue counts, Query gaps,
deletion counts, bypass evidence, facade evidence, and deletion line/removal
counts are visible, while the closeout certifier and row constructors remain
internal.

Synthetic proof, local support pins, copied rows, handoff-only receipts, raw
vectors, and string links are lower-authority material. They are represented as
rejected bypass evidence rows backed by the concrete lower-authority
compile-fail fixture and required authority type before the closeout report can
certify.

Explicit residue rows remain capped at the edge-split blueprint lane, the loop
reconstruction blueprint lane, and the residue manifest. Each residue row must
name an owner, cap, and removal trigger in the gate inventory and deletion
ledger.

Query capability gaps are currently zero. Adding one requires a named blocker in
the gate inventory, a matching deletion-ledger row, and this closeout count to
change in the same certification pass.

Broad 7.5 overlap-region extraction remains blocked until this closeout remains
green after any new overlap-region source is added to the audited matrix.
