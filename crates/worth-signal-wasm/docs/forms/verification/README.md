# Form Verification

Verification packages compare the controller's public projections: source,
draft, fields, patch, validation, readiness, actions, resources, routes,
presentation, and retained histories. They are useful in tests and diagnostic
tooling when “these two reports should agree” needs mechanical proof.

Verification artifacts and digests are evidence. They do not authorize action
execution, route transitions, resource replay, or restore.
