# Public Donor Certificate Triage - 2026-06-23

## Hypothesis

A public post-2020 finite unit-distance or distance-avoiding graph package may
provide a better certificate-bearing donor than `W_circles_607`.

The second-agent gate rejected a broad donor hunt and approved only
certificate-bearing triage. A candidate counts only if it has machine-readable
graph, coordinate, or weight data; exact-enough geometry; and a replayable
upper-bound or fractional certificate surface that is closer to crate authority
than the public W607 package.

## Decision

No public certificate-bearing finite donor was found in this bounded pass.

The only new certificate-bearing package is for a different problem: pointwise
lower bounds on the number of unit distances among `n` points. It does not
provide a finite weighted independent-set upper-bound certificate, a fractional
chromatic certificate, or an exact geometry object that interfaces with the G27
pressure machinery.

## Reactivation Criteria

Reopen public donor import only if a source provides:

- machine-readable finite graph, coordinates, and weights;
- exact or replayable algebraic geometry;
- a proof artifact, not only a solver transcript;
- one of: branch tree, rational LP dual, weighted cover, SAT/PB proof, or a
  documented solver certificate with independently replayable semantics;
- a quantitative HN route: finite weighted/fractional lower bound near W607/G27,
  or a reusable certificate format directly applicable to W607 or frozen fused
  channels.

## Next Hypothesis

Stop public donor hunting for now. The next fundable hypothesis should design a
minimal reusable MWIS upper-bound certificate format, then test whether an
external solver can emit enough branch, dual, or cover information for one
frozen near-miss channel or for base W607.
