# Recipes

These pages are short, copy-oriented examples for common Query jobs.

Use this section when you already know roughly what you want to do and you want
to see one practical call shape without reading a full feature doc first.

## Start Here

- [Prepare Preview From An Active Face Selection](./prepare-preview-from-active-face-selection.md)
  Progress one active-face declaration and ask Query for the preview-facing next
  step.
- [Attach Material With Declaration-Scoped Contributions](./attach-material-with-declaration-scoped-contributions.md)
  Run one declaration plus support, explanation, or workflow contribution
  meaning in one call.
- [Author A Grouped Neighborhood With Contributions](./author-a-grouped-neighborhood-with-contributions.md)
  Build one neighborhood-shaped operation with shared and member-local grouped
  meaning.
- [Turn A Stop Into A Recovery Action](./turn-a-stop-into-a-recovery-action.md)
  Convert one ordinary, checked, or proof-visible stop into the next repair
  step.

## How To Use These Pages

- start with a recipe when you want a working call shape first
- move to the linked feature docs when you need the full mental model
- prefer the feature docs for authority boundaries, support posture, and all
  available lanes
