# Adding a New Topology Operator

End-to-end guide for adding a topology operator to `forge-topo`.

**Reference implementation:** `MakeVertexFace` in
`topology/operations/entity_lifecycle/make_vertex_face.rs` — the simplest
operator, creates the topological seed.

---

## 1. Define the Operator Struct

The struct holds the operation's parameters. It must implement `Debug`.

```rust
#[derive(Debug)]
pub struct SplitEdge {
    pub edge: HalfEdgeId,
    pub parameter: f64,
}
```

For parameterless operators (e.g. `MakeVertexFace`), use a unit struct:

```rust
#[derive(Debug)]
pub struct MakeVertexFace;
```

---

## 2. Define the Output Struct

What handles the operator returns to the caller. Not `Debug` — it only
carries typed IDs.

```rust
pub struct SplitEdgeOutput {
    pub edge_a: HalfEdgeId,
    pub edge_b: HalfEdgeId,
    pub vertex: VertexId,
}
```

---

## 3. Implement `TopoOperator`

Three items:

| Item                                                                                         | Purpose                                                 |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| `type Output`                                                                                | The output struct from step 2                           |
| `const NAME: &'static str`                                                                   | String literal for lineage/replay (e.g. `"split_edge"`) |
| `fn execute(&self, draft: &mut MutableDraft, recorder: &mut LineageRecorder) -> Result<...>` | The topology mutation                                   |

```rust
use crate::operator::{TopoOperator, EulerDelta, ExecutionResult};
use crate::state::MutableDraft;
use crate::provenance::LineageRecorder;
use forge_core::KernelError;

impl TopoOperator for SplitEdge {
    type Output = SplitEdgeOutput;

    const NAME: &'static str = "split_edge";

    fn execute(
        &self,
        draft: &mut MutableDraft,
        recorder: &mut LineageRecorder,
    ) -> Result<ExecutionResult<Self::Output>, KernelError> {
        // — topology mutations go here —

        Ok(ExecutionResult {
            value: SplitEdgeOutput { edge_a, edge_b, vertex },
            declared_delta: EulerDelta {
                vertices: 1,
                half_edges: 2,
                faces: 0,
                loops: 0,
                edges: 1,
                shells: 0,
                solids: 0,
                lumps: 0,
                regions: 0,
            },
        })
    }
}
```

## 4. Inside `execute()` — Arena Mutation Patterns

### Creating entities

Use the `MutableDraft` proxy methods generated by `define_draft_proxies!`:

```rust
let vertex = draft.insert_vertex(VertexData::new(placeholder_he));
let face   = draft.insert_face(FaceData::new(placeholder_loop, shell));
let he     = draft.insert_half_edge(HalfEdgeData::new(
    radial_next, next, prev, face, origin, edge,
));
let loop_id = draft.insert_loop(LoopData::new(placeholder_he, face));
let edge    = draft.insert_edge(EdgeData::new(placeholder_he));
let shell   = draft.insert_shell(ShellData::new(placeholder_face, ShellKind::Sheet, region));
let region  = draft.insert_region(RegionData::new(lump));
let lump    = draft.insert_lump(LumpData::new(solid));
let solid   = draft.insert_body(BodyData::new());
```

### Wiring pointers

Use `draft.arena_mut()` to get mutable access for pointer updates:

```rust
draft.arena_mut().get_half_edge_mut(he)?.set_next(other_he);
draft.arena_mut().get_half_edge_mut(he)?.set_prev(other_he);
draft.arena_mut().get_half_edge_mut(he)?.set_radial_next(twin);
draft.arena_mut().get_vertex_mut(vertex)?.set_primary_disk(he);
draft.arena_mut().get_face_mut(face)?.set_outer_loop(loop_id);
draft.arena_mut().get_loop_mut(loop_id)?.set_half_edge(he);
```

### Removing entities

```rust
let removed_data = draft.remove_face(face_id)?;
let removed_data = draft.remove_half_edge(he_id)?;
```

### Accessing the lineage store

When you need to interact with the lineage store manually (e.g.
to stamp lineage on newly created entities), use the provided `recorder`:

```rust
use forge_core::{EntityRef, EntityKind};
recorder.stamp(draft.lineage_store_mut(), EntityRef::new(EntityKind::Vertex, vertex.index(), vertex.generation()));
```

### Placeholder handles

Use `HalfEdgeId::new(u32::MAX, 0)` (or equivalent) for circular
references that must be patched after creation.

## 5. `EulerDelta` — Declared vs Actual

Every code path in the operator must declare its `EulerDelta` — the
expected change in entity counts. The `MutableDraft::execute()` runner
compares this against actual arena count changes **after** your
`execute()` returns. A mismatch produces a `KernelError`.

Different branches may declare different deltas. For example, `SplitEdge`
has a self-loop path and a normal path with different half-edge counts.

```rust
// Normal path
EulerDelta { vertices: 1, half_edges: 2, edges: 1, ..Default::default() }

// Self-loop path
EulerDelta { vertices: 1, half_edges: 1, edges: 1, ..Default::default() }
```

## 6. Register the Operator

Add your operator file to the appropriate directory under
`topology/operations/` and re-export from `mod.rs`:

```
topology/operations/entity_lifecycle/
├── mod.rs                  ← add `pub mod split_edge;`
├── make_vertex_face.rs
├── make_edge_face.rs
├── split_edge.rs           ← your new file
└── ...
```

In `entity_lifecycle/mod.rs`:

```rust
pub mod split_edge;
```

---

## 7. Call Site

Callers use `draft.execute(op)`:

```rust
let state = TopologyState::empty();
let mut draft = state.into_mutation();

let result = draft.execute(MakeVertexFace)?;
let mvf = result.into_value();

let result2 = draft.execute(MakeEdgeVertex {
    face: mvf.face,
    // ...
})?;
let mev = result2.into_value();

let committed = draft.commit()?;
```

`draft.execute()` returns `Result<OperationResult<O::Output>, KernelError>`.
Call `.into_value()` to extract the output. The `OperationResult` also
carries `DecisionLog`, `OperationMetrics`, and `LineageDelta`.

## 8. Testing

Write unit tests in the `entity_lifecycle/tests/` directory (or alongside
the operator file). Each test should:

1. Create a `TopologyState::empty()` and `into_mutation()`
2. Execute the operator (and any prerequisite operators)
3. Assert handle validity and pointer correctness
4. Assert `draft.commit()` succeeds (structural validation passes)

```rust
#[test]
fn split_edge_creates_correct_topology() {
    let state = TopologyState::empty();
    let mut draft = state.into_mutation();

    // Set up prerequisite topology...
    let mvf = draft.execute(MakeVertexFace).unwrap().into_value();

    // Execute the operator under test
    let result = draft.execute(SplitEdge {
        edge: mvf.half_edge,
        parameter: 0.5,
    }).unwrap().into_value();

    // Assert connectivity
    let v = draft.arena().get_vertex(result.vertex).unwrap();
    assert_ne!(v.primary_disk(), HalfEdgeId::new(u32::MAX, 0));

    // Assert commit (structural validation)
    assert!(draft.commit().is_ok());
}
```

### What the runner already validates for you

- **EulerDelta mismatch** → error on `draft.execute()` return
- **Twin/next/prev reciprocity** → validated when `per_op_validation` is on
- **Structural validation** → validated at `commit()` (Euler formula, loops,
  manifold edges, hierarchy)

## Checklist

- [ ] Operator struct defined with `#[derive(Debug)]`
- [ ] Output struct defined
- [ ] `TopoOperator` implemented (`execute`, `const NAME`)
- [ ] Every code path returns correct `EulerDelta`
- [ ] No raw `f64` comparisons (pure connectivity)
- [ ] Registered in `mod.rs`
- [ ] Unit tests pass with `draft.commit()` succeeding
- [ ] `semantic_summary()` overridden if parameters are meaningful
