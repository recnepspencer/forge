   - **Implementation**: Updated both `DemoTwo.tsx` and `DemoFive.tsx` to conform to the correct declarative top-level validation structure, rendering the error texts dynamically underneath the title fields.

6. **WASM Object Snapshot Caching in `useSignal` (Infinite Loop & Borrow Panic Fix)**:
   - **Root Cause**: Since object signals compiled in WASM yield newly-minted JavaScript object references on every `.value()` call, returning these raw references in `useSyncExternalStore`'s `getSnapshot` led to an infinite React re-render loop and WASM `RefCell already borrowed` crashes.
   - **Resolution**: Implemented a structural cache ref inside the hook. When `getSnapshot` triggers, it performs a structural equality check (using a fast JSON stringify compare) against the cached value. If they are structurally equivalent, it yields the same cached object reference. This perfectly stabilizes the render cycle and completely eliminates infinite loops and borrow crashes.
