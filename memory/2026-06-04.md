# 2026-06-04

- Hadwiger research spec direction: keep `hadwiger-research` as one crate with
  Query as the public entry point, including pre-runtime declaration handles.
- Runtime Bridge, Signal, and Relational power should stay underneath Query;
  Hadwiger surfaces may carry lower-runtime-shaped evidence but should not
  expose lower runtimes as ordinary public entry points.
- Failure memory should live on the research graph where possible so repeated
  dead ends can become structurally unadmittable or suppressible before
  candidate generation.
- Relational extensible invariants should be used for research-graph legality
  below graph truth, not for theorem authority. Add catalog/violation/denial
  artifacts now, but delay always-on relational registration until graph-memory
  schema, failure scopes, suppression semantics, and branch-promotion rules are
  stable.
- Implemented `hadwiger-research` Phase 2 as a Query-derived canonical artifact
  layer: graph/version, embedding/checker, colorability, gadget/reduction, proof
  candidate, and AI advisory artifacts now have stable foundational digests,
  source/parent references, read-only authority owners, and compile-time guards
  against admitted theorem/proof authority or raw digest construction.
- Implemented `hadwiger-research` Phase 3 as an aspect authority and dependency
  closure layer: typed aspect records, dependency graph builders, deterministic
  closure reports, conservative invalidation posture, recompute/promotion
  descriptors, Query aspect mappings, and Query-owned binding stop wrappers.
  Phase 3 still deliberately avoids checker execution, theorem authority,
  runtime bridge/signal work, and relational invariant registration.
- Phase 3 QA found and fixed a closure identity weakness: closure digests now
  include closure graph identity and present aspect stable tokens, so changed
  artifact/source evidence cannot disappear behind identical aspect-kind
  topology. Added tests for digest sensitivity, advisory non-satisfaction of
  mathematical dependencies, and the full Query aspect path matrix.
- Implemented `hadwiger-research` Phase 4 as real checker admission pipelines:
  no mock checker facade remains; exact unit-distance verification, Varisat CNF
  solving with in-crate SAT model replay / bounded UNSAT refutation replay, and
  the classical hexagonal seven-color construction verifier now enter through
  Query declarations before producing checker-owned artifacts and admitted math
  aspects.
- Phase 4 QA found and fixed two foundation gaps: UNSAT refutation replay now
  independently exhausts the bounded assignment space instead of only comparing
  clauses, and checker artifacts now retain typed Query declaration references.
  The public mocked operating context was removed so the crate no longer exposes
  a mock checker lane.
- Phase 4 structural/test QA moved checker math into a real
  `mathematical_verification` subsystem with exact unit-distance, finite SAT
  colorability, and hexagonal plane-coloring responsibilities. The top-level
  integration-test pile was split into responsibility runners/folders, and the
  compile-fail authority fixtures were subdivided so no test directory exceeds
  the 10-file cap.
- After pulling `origin/master`, `crates/forge-query/docs/AI_README.md` became
  the preferred Query navigation doc. Updated Hadwiger milestone 1 to require
  Query retained-artifact-to-next-step, binding/resolver, grouped,
  recovery-brief, and projection-consumption lanes where they fit, and to make
  Phase 5 authority chains/background theorem retention explicit.
- Implemented `hadwiger-research` Phase 5 as a sealed proof-claim admission
  layer: proof claim intent is declared through Query, lower/upper/background
  theorem authority is admitted only through checked operations, proof authority
  chains retain Query/checker/aspect/background references, and compile-fail
  boundaries guard against public admitted proof constructors or unchecked
  admission functions. Public end-to-end lower-bound coverage uses the honest
  small real-checker case `chi(plane) >= 2` from a unit edge plus not-1
  colorability; larger `>= 6` coverage still needs a real finite unit-distance
  not-5-colorable fixture.
