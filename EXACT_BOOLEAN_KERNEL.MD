# Exact Boolean Kernel — Engineering Specification

## Problem Statement

The current boolean pipeline relies on 64-bit floating-point heuristics, ray-casting classification, and dot-product/area-based coplanar overlap resolution. These approaches fail catastrophically and non-deterministically under extreme scale variations ($10^{12}$ to $10^{-9}$), non-manifold input geometry, and massive coplanar avalanches. We need a bulletproof, exact mathematical foundation to eliminate floating-point drift, inherently resolve degeneracies, and safely leverage data parallelism without mutex bottlenecks.

## Existing Foundation (What We Have)

| Primitive                  | Location                       | Status                                                  |
| -------------------------- | ------------------------------ | ------------------------------------------------------- |
| Generational Arena         | `forge-topo/src/arena.rs`      | ✅ Full zero-cost graph safety.                         |
| Transactional Rollbacks    | `forge-topo/src/state.rs`      | ✅ `ArenaSnapshot` / `MutableDraft` patterns.           |
| Queue Decimator            | `cleanup.rs`, `postprocess.rs` | ✅ Functional sliver collapse.                          |
| Ray-Casting Classification | `classify.rs`                  | ⚠️ Working but mathematically brittle on open meshes.   |
| Exact Rational Fallbacks   | `VertexMatchKey` / `eval.rs`   | ⚠️ Partially implemented, prone to bit-width explosion. |

## Architecture: 3 Layers, No New Crates

The exact boolean implementation introduces no new crates, but strictly maps algorithms into our established layering model.

**Layer 1: Exact Numerical Core (`forge-math`)**
**Layer 2: Symbolic Geometry & Bounding (`forge-geom`)**
**Layer 3: Topo-Parallel Orchestration & Classification (`forge-kernel`)**

## Proposed Changes

### Layer 1 — Exact Numerical Core (`forge-math`)

[NEW] `forge-math/src/arithmetic/filter.rs`
This is the lowest-level foundation. We use a cascading function that attempts fast `f64` math, computes the dynamic error bound, and enforces an exhaustive enum return.

```rust
use malachite::Rational; // Arbitrary-precision exact arithmetic

/// The mathematically undeniable sign of a geometric determinant.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Sign {
    Positive,
    Negative,
    Zero, // Represents a true geometric degeneracy (e.g., exactly coplanar)
}

/// The 3D orientation predicate: Is point D above, below, or on plane ABC?
pub fn orient3d_filtered(pa: &[f64; 3], pb: &[f64; 3], pc: &[f64; 3], pd: &[f64; 3]) -> Sign {
    // 1. Phase 1: Fast Hardware f64 Evaluation
    let det_approx = compute_orient3d_f64(pa, pb, pc, pd);

    // 2. Phase 2: Dynamic Error Bound Calculation
    let error_bound = compute_orient3d_error_bound(pa, pb, pc, pd);

    // 3. Phase 3: The Filter Check
    if det_approx.abs() > error_bound {
        if det_approx > 0.0 { return Sign::Positive; }
        return Sign::Negative;
    }

    // 4. Phase 4: Exact Arbitrary-Precision Fallback
    orient3d_exact_rational(pa, pb, pc, pd)
}

fn orient3d_exact_rational(pa: &[f64; 3], pb: &[f64; 3], pc: &[f64; 3], pd: &[f64; 3]) -> Sign {
    unimplemented!() // Convert f64 -> malachite::Rational (lossless), compute exact determinant
}
```

```rust
pub fn orient3d_sos(pa: SosPoint, pb: SosPoint, pc: SosPoint, pd: SosPoint) -> Sign {

    if exact_sign != Sign::Zero { return exact_sign; }

    if parity % 2 == 0 { Sign::Positive } else { Sign::Negative }
```

### Layer 2 — Symbolic Geometry & Bounding (`forge-geom`)

[NEW] `forge-geom/src/primitives/implicit_vertex.rs`
To prevent compounding floating-point drift and rational bit-width explosion, vertices generated by cuts are stored immutably as the intersection of their parent planes.

```rust
use forge_topo::handles::PlaneId;
use malachite::Rational;

pub struct ExactPlane {
    pub a: Rational, pub b: Rational, pub c: Rational, pub d: Rational,
}

pub enum VertexGeometry {
    Explicit([Rational; 3]),
    Symbolic { p1: PlaneId, p2: PlaneId, p3: PlaneId },
}

impl VertexGeometry {
    pub fn classify_against_plane(&self, target_plane: &ExactPlane, plane_table: &PlaneTable) -> Sign {
        match self {
            VertexGeometry::Explicit(coords) => evaluate_plane_equation(target_plane, coords),
            VertexGeometry::Symbolic { p1, p2, p3 } => {
                let p1 = plane_table.get(*p1); let p2 = plane_table.get(*p2); let p3 = plane_table.get(*p3);
                compute_4x4_plane_determinant(p1, p2, p3, target_plane)
            }
        }
    }
}
```

[NEW] `forge-geom/src/primitives/polytope.rs`
Converts infinite mathematical half-spaces into bounded, solid B-Rep meshes.

```rust
use forge_topo::state::MutableDraft;
use forge_topo::handles::FaceId;

pub struct MasterBoundingBox {
    pub min: [f64; 3],
    pub max: [f64; 3],
}

impl MasterBoundingBox {
    pub fn clip_halfspace(&self, halfspace_plane: &ExactPlane, draft: &mut MutableDraft) -> Result<Vec<FaceId>, KernelError> {
        let mut box_faces = self.instantiate_in_arena(draft);
        let mut surviving_faces = Vec::new();

        for face in box_faces {
            match classify_face_against_plane(draft, face, halfspace_plane) {
                Sign::Positive => {},
                Sign::Negative => surviving_faces.push(face),
                Sign::Zero => {
                    let fragments = split_face_by_plane(draft, face, halfspace_plane)?;
                    surviving_faces.extend(fragments.inside_fragments);
                }
            }
        }
        let cap_faces = triangulate_open_boundary(draft, surviving_faces.boundary_edges())?;
        surviving_faces.extend(cap_faces);
        Ok(surviving_faces)
    }
}
```

### Layer 3 — Topo-Parallel Orchestration (`forge-kernel`)

[MODIFY] `forge-kernel/src/operations/boolean/classify/eval.rs`
Replaces brittle ray-casting with Generalized Winding Numbers using exact solid angle integration.

```rust
use std::f64::consts::PI;

pub fn compute_solid_angle(p: &[f64; 3], v1: &[f64; 3], v2: &[f64; 3], v3: &[f64; 3]) -> f64 {
    let a = [v1[0] - p[0], v1[1] - p[1], v1[2] - p[2]];
    let b = [v2[0] - p[0], v2[1] - p[1], v2[2] - p[2]];
    let c = [v3[0] - p[0], v3[1] - p[1], v3[2] - p[2]];

    let det = dot(&a, &cross(&b, &c));
    let al = norm(&a); let bl = norm(&b); let cl = norm(&c);

    let div = al * bl * cl + dot(&a, &b) * cl + dot(&b, &c) * al + dot(&c, &a) * bl;
    2.0 * f64::atan2(det, div)
}

pub fn is_point_inside_mesh(query_point: &[f64; 3], mesh_bvh: &BvhNode<FaceId>, geometry: &GeometryStore) -> bool {
    let total_solid_angle = accumulate_winding_number(query_point, mesh_bvh, geometry);
    let winding_number = total_solid_angle / (4.0 * PI);
    winding_number > 0.5
}
```

## Acceptance Criteria

- **AC-1: SoS Determinism**
  Perfectly coplanar overlapping faces (e.g., identical Z-planes) must consistently resolve into non-intersecting layers derived from lexicographical tie-breakers (`PlaneId` / `VertexId`), producing zero topological Z-fighting.
- **AC-2: Exact Predicate Speed**
  Evaluating 1M non-degenerate intersections must successfully route through the `f64` hardware filter > 99.9% of the time, keeping the arbitrary-precision solver out of the hot path.
- **AC-3: GWN Robustness**
  Volumetric classification must correctly identify a point as `Inside` (`solid angle / 4π > 0.5`) even if the mesh is an open shell or contains $10^{-12}$ gaps.
- **AC-4: Concurrent Splitting Speedup**
  Switching to Rayon `par_iter()` for non-overlapping spatial nodes must yield $>1.5\times$ speedup on the `mb7_micro_feature_avalanche` benchmark relative to sequential queuing.

## Unknowns & Research Required

1. **Rayon Mutability during Split:**
   Topology mutations require a `MutableDraft`. To prevent mutex locking across parallel splits, we may need a Map-Reduce architecture: parallel BSP node intersecting (Map) resulting in un-committed geometric cuts, followed by a deterministic sequential Euler Operator sweep (Reduce).
2. **GWN BVH Hierarchy Optimization:**
   Computing winding numbers over 10K faces is $O(N)$ per query point. We must implement hierarchical approximation using the existing BVH (treating distant groups of faces as a single dipole) to reduce evaluation to $O(\log N)$.
