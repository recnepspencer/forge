# worth-store-blob-chunks

Owns Roadmap 2 S.7 and the substrate for Roadmap 1 Milestone 20: native
content-addressed chunk trees, streaming ingest/read/export/import, dedupe,
resumable writes, reachability, and chunk-level corruption localization.

Blob bytes live inside the Store physical foundation. This is not a metadata
table beside an external file server.
